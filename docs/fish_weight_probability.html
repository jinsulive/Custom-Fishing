读表须知

  • 概率是「同一时刻池内」的概率：插件会把所有条件成立的组权重累加到同一个池，因此父组与所有命中的子组是叠加关系，不是互斥。
  • 表内概率默认手持自定义钓竿。手持原版钓竿时 special_water_loots 不生效，特殊鱼与宝箱概率全部为 0，只剩原版鱼与杂物。
  • 权重 ≤ 0 的条目被源码直接剔除：例如海洋分支 rubbish:-6 在叠加基础 +8 后为 2，而单独出现负数时该条不参与抽取。
  • group_for_each 是「每个成员各加 N」，不是把 N 均分给组内成员，所以组越大，该组提供的总权重越大。
  • 场景之间可以进一步叠加，例如「深海 + 夜 + 满月 + 乘船」会同时命中多条分支，实际概率以当时全部条件为准。
  • 未在本表出现的鱼：blue_jellyfish, blue_jellyfish_golden_star, blue_jellyfish_silver_star, pink_jellyfish, pink_jellyfish_golden_star, pink_jellyfish_silver_star（权重表未引用，正常钓取不到）。
