## 一、计算口径（已对照 Java 源码逐条核对）

| 项 | 口径 |
|---|---|
| 权重池 | 初始 0；`id:+N`、`group_for_each:A&B:+N`（交集每员各+N）无条件加减；≤0 出池 |
| 竿 group-mod | 只对池中**权重>0**条目生效（forAvailable=true） |
| group-mod-ignore-conditions | getOrDefault(0) 相加，**可新建条目**（秘法竿附魔书） |
| 等待时间 | clamp(rand(100,600)tick × 竿倍率, 50, 1200)，取期望 |
| 小游戏 | game-conditions 权重抽取；限时=配置time+竿game-time；仅非 disable-game 战利品触发 |
| 单轮周期 | 平均等待 + 期望小游戏限时（必成功口径；实际失败再乘 1/成功率） |
| 售价 | 0.2×base + 0.1×bonus×size均值；寒霜竿 size×1.25 只放大 bonus 项 |
| 多重收获 | 海神竿 0.3 → 每成功渔获期望 1.3 件 |
| 日限额 | 5,000 憨币/日（market.limitation.earnings） |
| 不含 | 鱼饵/鱼钩加成、周末大赛全局 0.85 等待、比赛期收益 |

> 宝箱/鱼饵袋未设 disable-game，**会触发小游戏**；`vanilla`（原版鱼）同样未设——
> 即当前配置下原版鱼也要打小游戏（约10~13%概率），如有意纯原版掉落建议补 `disable-game: true`。
> 难度差（difficulty）不影响限时，只影响成功率——周期按必成功计，高难度竿实际周期更长。
> 「触限额h」= 5000 ÷ 收益/h；∞ 表示市价 0 永不触顶；8h收益 = min(8×收益/h, 5000)。

## 八、关键发现

0. **秘法钓竿已按需求排除**：它被 `water_loots` 顶层 `!rod: magical_rod` 排除后，全池仅剩 ignore-conditions 新建的附魔书条目——市价 0、16 耐久、2.5 倍等待，经济效率为 0，故不参与本次测算。
1. **`vanilla` 原版鱼也会触发小游戏**（配置未设 disable-game）：水域中约 10~13% 的咬钩是「打小游戏 → 得原版鱼」。若想要纯原版掉落体验，需给 `contents/item/default.yml` 的 `vanilla` 补 `disable-game: true`。
2. **白骨钓竿夜间水中有骷髅彩蛋**：`skeletons` 条件树在 in-water+夜 追加 skeleton:+30、熔岩追加 wither_skeleton:+25（不占小游戏），夜间河流/海洋池被显著稀释。
3. **风暴竿强天气依赖**：仅雨/雷暴时等待 ×0.65（11.4s，全场最短）；晴天与普通竿相同（17.5s）。但 storm 组只有电鳗 3 个变体，加成面太窄——雷暴河流收益仍输给炽焰竿（约1.2k vs 1.7k/h）。想让风暴竿有竞争力，应扩大 storm 组成员或提高权重。
4. **海神竿是收益之王**：30% 双重收获 + 海洋系 +6/巨物 +5，海洋场景收益最高；且 game-time+5 小幅拉长周期。
5. **群星竿+15s 小游戏**大幅拉长单轮，但提高成功率（时间充裕）——本表按必成功口径，对新手实际收益可能反而更好。
6. **熔岩/虚空只有专属竿能钓**：白骨/炽焰（熔岩）、虚空幽影（虚空），其余竿 N/A。
7. **日限额 5000 是硬天花板**：多数竿×水域组合 1~5 小时即触顶（下界熔岩/底层虚空 0.7~0.9h 最快），触顶后边际收益归零；唯一 8 小时吃不满限额的是「白骨竿×主世界熔岩湖」（8h 约 4,722）。冲榜玩家触顶后应转向图鉴/统计/比赛价值，或官方调整限额/分场景限额。
