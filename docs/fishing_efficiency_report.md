# Custom-Fishing 全杆 × 全水域 效率与限额测算报告

- 数据来源：`loot-conditions.yml` / `game-conditions.yml` / `contents/rod/default.yml` / `contents/hook/default.yml` / `contents/minigame/default.yml` / `contents/item/*.yml` / `config.yml`

## 一、计算口径（已对照 Java 源码逐条核对）

| 项 | 口径 |
|---|---|
| 权重池 | 初始 0；`id:+N`、`group_for_each:A&B:+N`（交集每员各+N）无条件加减；≤0 出池 |
| 竿/钩 group-mod | 只对池中**已存在**条目生效（`forAvailable=true`，`previous != null` 才写入） |
| group-mod-ignore-conditions | `getOrDefault(0)` 相加，**可新建条目**（秘法竿附魔书） |
| 等待时间 | `before ~ U{100..600}` tick；`after = clamp((int)(before×倍率+加值), 50, 1200)`；按 501 个整数点求期望 |
| 小游戏 | `game-conditions` 按条件加权抽取（含 `loot` / `group` 条件）；`限时 = time×倍率+加值`；`disable-game` 的战利品跳过 |
| 单轮周期 | 平均等待 + 期望小游戏限时（**必成功口径**；失败重钓不计） |
| 体长 | `rand[min,max]×sizeMultiplier+sizeAdder`，`restricted-size-range: true` 时再夹回 `[min,max]` |
| 售价 | `0.2×base + 0.1×bonus×size均值`；无 `size` 的条目按 size=0 计 |
| 多重收获 | `amount = ⌊p⌋ + (rand<p−⌊p⌋ ? 2 : 1)`，p=0.5 时每竿期望 **1.5 件** |
| 熔岩 / 虚空 | **统一配对应鱼钩**：熔岩用 `obsidian_hook`（lava+6），虚空用 `void_hook`（void+6） |
| 风暴雷霆竿 | **默认雷暴天气**：无条件吃 `wait×0.5`、`difficulty −5`，河流场景额外吃 `stormy_freshwater` 组 |
| 日限额 | 5,000 憨币/日（`market.limitation.earnings`） |
| 不含 | 鱼饵加成、周末大赛全局 0.85 等待、比赛期收益、耐久消耗 |

> 熔岩 / 虚空场景对全部 11 竿统一「竿 + 专属鱼钩」测算，这样比较口径一致；白骨 / 炽焰 / 虚空幽影本身具备该能力，不挂钩也能进，但表内数值含鱼钩的 +6 权重。
> 风暴竿在熔岩 / 虚空不享受天气加成（下界与末地无天气，主世界熔岩湖按晴天计）。
> 「触限额h」= 5000 ÷ 收益/h；「8h收益」= min(8×收益/h, 5000)。
> 秘法竿被 `water_loots` 顶层 `!rod: magical_rod` 排除，全池只剩 ignore-conditions 新建的附魔书（市价 0），经济效率为 0，不参与测算。

## 十、关键发现

1. **收益天花板是「海神潮汐钓竿 × 世界底层深渊虚空（Y<-55）」**：10,632 憨币/h，0.47 小时吃满日限额；限额 5000 是所有场景的硬顶，其余组合只是触顶快慢的区别。
2. **群星竿的「幸运系 +10」只在淡水生效**：以同样无权重加成的白骨竿为基准，海洋 1,498 vs 1,498，完全同值（`lucky` 组只有三档祥瑞金锦鲤，且都属于 `river`）；河流 1,216 vs 1,076，提升 13.0%。想让它在海洋也有效，得把幸运鱼扩进海洋/熔岩池，或改挂 `golden_star` 这类通用星级组。
3. **海神潮汐竿是海洋之王**：50% 双重收获（每竿期望 1.5 件）+ 巨物 +10 / 海洋 +6，海洋场景单轮 36.1s 却拿到 4,396 憨币/h，1.14h 触顶；巨物 +10 同时抬高了海洋分母，打捞箱类容器概率被进一步摊薄。
4. **风暴雷霆竿现在只看天气**：雷暴下等待 17.5s → 8.7s，河流 1,499 憨币/h；晴天下它与同权重竿完全等价——它是「雷雨天专用爆发竿」，不是常驻收益竿。
5. **岩浆/虚空靠鱼钩就能全员下海**：配 `obsidian_hook` 后任意竿都能进熔岩，但白骨竿×主世界熔岩湖仍是最差组合（1,449 憨币/h）——该池 65% 权重是石头/圆石/燧石/黑曜石之类零价杂物；下界池才是熔岩收益的主力。
6. **所有 88 个组合都能在 8 小时内吃满 5,000 日限额**：最慢的「新手钓竿 × 河流（晴/昼）」也只要 5.63h 触顶，触顶后所有场景的 8h 平均效率都收敛到 625 憨币/h——真正的差距只在「多快吃满」，不在「能吃多少」。
7. **小游戏时长已无竿间差异**：群星 / 海神的 `game-time` 全部撤掉后，单轮周期差异只剩等待时间与池构成，星级权重竿（白银/黄金/大师/海神）因为把高星鱼权重抬高，会被抽到更长的小游戏，单轮反而略长。
