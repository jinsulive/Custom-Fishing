## 说明

- **星级变体规则**：除彩虹七彩神鱼外，每种鱼都有 3 个变体——基础（`_no_star` 无后缀）、`_silver_star`（白银）、`_golden_star`（黄金）；CMD 依次 +1、+2。合计 53 种鱼共 **157 个物品条目**。
- **已排除项**：`default.yml` 顶部的 `vanilla:` 段（原版鳕鱼、鲑鱼、热带鱼、河豚的掉落配置）以及 `stick`、`shoes`、`rubbish`（核辐射变异鱼，CMD 50000）等非鱼类杂物。
- 高价值神话鱼（奇点坍缩星核鱼、幼年利维坦、九天星穹苍龙鲤）带 `special_game` 组，钓获时有全服广播；黄金之星基础价最高的是奇点坍缩星核鱼（888）。
