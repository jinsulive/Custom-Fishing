## 一、玩家常用（3 条）

| 命令 | 参数 | 权限节点 | 可执行者 | 说明 |
|---|---|---|---|---|
| `/cfishing reload`<br>`/customfishing reload` | — | `customfishing.command.reload` | 任意 | 重载配置，支持 `-s` |
| `/sellfish` | — | `customfishing.sellfish` | 仅玩家 | 打开卖鱼界面 |
| `/fishingbag` | — | `fishingbag.user` | 仅玩家 | 打开自己的钓鱼袋 |

## 二、物品（4 条）

| 命令 | 参数 | 权限节点 | 可执行者 |
|---|---|---|---|
| `/cfishing items get` | `<id> [amount]`，`-t` 直接进背包，`-s` 静默 | `customfishing.command.getitem` | 仅玩家 |
| `/cfishing items give` | `<player> <id> [amount]`，`-t`、`-s` | `customfishing.command.giveitem` | 任意 |
| `/cfishing items give-by-uuid` | `<uuid> <id> [amount]`，`-t`、`-s` | `customfishing.command.giveitem` | 任意 |
| `/cfishing items import` | `<id>` | `customfishing.command.importitem` | 仅玩家 |

`amount` 取值范围为 1~6400。`items import` 会将主手物品写入 `plugins/CustomFishing/imported_items.yml`，以 `id` 作为键；它不会从文件向背包导入物品。

## 三、竞赛（3 条，共用 `customfishing.command.competition`）

| 命令 | 参数 | 行为 |
|---|---|---|
| `/cfishing competition start` | `<id> [group]` | 启动指定赛事，可强制指定服务器组 |
| `/cfishing competition end` | — | 立即结算并发放奖励（`end(true)`） |
| `/cfishing competition stop` | — | 中止比赛、清空排行，**不发奖**（`stop(true)`） |

三者都支持 `-s`，并且都可以由任意发送者执行。

## 四、界面与背包（4 条）

| 命令 | 参数 | 权限节点 | 可执行者 |
|---|---|---|---|
| `/cfishing open market` | `<player>` | `customfishing.command.open.market` | 任意 |
| `/cfishing open bag` | `<player>` | `customfishing.command.open.bag` | 任意 |
| `/cfishing fishingbag edit-online` | `<player>` | `customfishing.command.edit.bag` | 仅玩家 |
| `/cfishing fishingbag edit-offline` | `<uuid>` | `customfishing.command.edit.bag` | 仅玩家 |

`open bag <player>` 打开的是**该玩家自己的**袋子；`edit-online` 和 `edit-offline` 才会以管理员身份开启他人袋子内容。

## 五、数据（3 条，共用 `customfishing.command.data`）

| 命令 | 参数 | 可执行者 | 说明 |
|---|---|---|---|
| `/cfishing data unlock` | `<uuid\|player>` | 任意 | 解锁被锁定的玩家数据 |
| `/cfishing data export` | — | **仅控制台** | 导出数据 |
| `/cfishing data import` | `<file>` | **仅控制台** | 从文件导入数据 |

## 六、统计（4 条，共用 `customfishing.command.statistics`）

| 命令 | 参数 |
|---|---|
| `/cfishing statistics set` | `<player> <type> <id> <value>` |
| `/cfishing statistics add` | `<player> <type> <id> <value>` |
| `/cfishing statistics reset` | `<player>` |
| `/cfishing statistics query` | `<player> <type>` |

`type` 只有两个取值：`MAX_SIZE`（最大体长）、`AMOUNT_OF_FISH_CAUGHT`（钓获总数）。`id` 的补全列表来自已注册且 `disable-stats` 不为 true 的战利品 ID。

## 七、调试（3 条，共用 `customfishing.command.debug`，仅玩家）

| 命令 | 参数 | 说明 |
|---|---|---|
| `/cfishing debug loot` | `<lava\|water\|void> [page]` | 查看周围战利品池，**必须手持钓竿** |
| `/cfishing debug biome` | — | 输出所在群系 |
| `/cfishing debug snbt` | — | 输出主手物品 SNBT，点击可复制 |

## 八、权限声明现状（需要注意）

`plugin.yml` 中只声明了 3 个权限：

| 节点 | 默认值 |
|---|---|
| `fishingbag.user` | true（所有人） |
| `customfishing.sellfish` | true（所有人） |
| `fishingbag.collectloot` | false（需显式授予，见 `config.yml` 的 `collect-requirements`） |

而 `customfishing.command.*` 共有 11 个节点（reload、getitem、giveitem、importitem、competition、open.market、open.bag、edit.bag、data、statistics、debug）、以及 `fishingbag.rows.1`~`6`（背包行数，未授予时固定 1 行），**都没有在 `plugin.yml` 中声明**。这意味着这些节点的默认值不由插件定义，而是由服务端权限插件决定；如果你的服务器安装了 LuckPerms，建议给管理组显式 grant，并给普通组显式 set 为 `false`（显式拒绝比依赖“未声明时的默认行为”更稳妥）。

## 九、其他要点

- `/customfishing` 与 `/cfishing` 完全等价，两者各自注册了同一套子命令。
- 通用 flag：`-s` / `--silent` 表示不输出提示；`-t` / `--to-inventory` 表示物品直接进背包（仅 `items get`、`give`、`give-by-uuid` 有该 flag）。
- `commands.yml` 的修改**必须重启服务器**才能生效（文件头注释已注明），`reload` 无法重新加载。
- 每条命令都可以通过 `enable: false` 单独关闭，`permission` 字段也可以改成任意自定义节点。
