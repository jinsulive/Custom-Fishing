## 三点需要注意的影响因素

1. **`vanilla:+60` 是最大的分母项**：它单独占淡水总权重的 17.2%，产原版鱼（售价 0）。这也是水域容器概率被压到 2% 出头的主因。
2. **装备加成会稀释容器概率**。`group-mod` 只给「已在池内」的鱼加权重，不改容器权重，所以分母抬高、容器概率下降：

    - 白银钓竿（silver_star +8）：淡水分母 348 → 452，容器 2.30% → **1.77%**
    - 黄金钓竿（golden_star +3）：分母 348 → 387，容器 2.30% → 2.07%
    - 海神潮汐钓竿（ocean +6、titan +10）：海洋分母被进一步抬高，容器 1.79% → **约 1.0%**

3. **双重渔获等于抽两次**。海神潮汐钓竿 50%、波塞冬之冠 15% 会触发 multiple-loot，同一竿抽 2 件，容器的**期望产出翻倍**（概率不变）。

> 补充：表中「裸装」指未装备带权重加成的钓竿 / 钓钩 / 诱饵 / 附魔；条件越多（夜间、樱花林、沼泽、满月、雷暴、乘船），命中池越多、分母越大，箱子越难出。
